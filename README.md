# Јовица Вратница — лична биографија

Лични сајт који представља животни пут, уверења, грађански ангажман и пројекте.

## Технологија
- Astro
- Markdown/компоненте за садржај
- GitHub Pages за објављивање

## Локални развој
```bash
npm install
npm run dev
```

## Изградња
```bash
npm run build
```

## Објављивање
GitHub Actions workflow у `.github/workflows/deploy.yml` аутоматски гради и објављује сајт на GitHub Pages када се промени `main`.

У GitHub репозиторијуму отворити **Settings → Pages** и као извор изабрати **GitHub Actions**.

## Уређивање садржаја
Почетна страница је у `src/pages/index.astro`. Личне приче се додају постепено, на основу проверених података и сећања — без измишљања детаља.
